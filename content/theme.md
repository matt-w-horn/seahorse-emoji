The terminal rotates through twelve non-green color palettes across the 24-hour clock (one station every two hours). Each palette defines three base CSS custom properties (`--background`, `--foreground`, and `--accent`), from which secondary UI tokens (`--dim` and `--line`) are mixed in sRGB and the 3D wireframe game's entity colors are derived via hue rotation.
